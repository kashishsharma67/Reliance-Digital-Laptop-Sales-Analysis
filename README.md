# Reliance Digital Laptop Sales Analysis

## Project Overview
An end-to-end data analytics project focused on analyzing laptop sales, customer behavior, product performance, store performance, revenue, returns, and delivery trends.

The project uses an AI-generated simulated dataset inspired by a Reliance Digital retail business case study. It does not contain actual company data and is not an official Reliance Digital project.

## Project Objectives
- Analyze sales and revenue performance.
- Understand customer purchasing behavior.
- Evaluate product and store performance.
- Identify return and cancellation trends.
- Examine payment methods and delivery performance.
- Develop actionable business insights through SQL and Power BI.

## Dataset Overview
- Records: 203,200
- Columns: 57
- Data type: AI-generated simulated retail data
- Subject: Laptop sales and transactions

## Tools & Technologies
- MySQL – Data cleaning, transformation, database design, and SQL analysis.
- Microsoft Excel – Data inspection and preparation.
- Power BI – Interactive dashboard development.

## Project Workflow
1. Data understanding and inspection
2. Data importation into MySQL
3. Data cleaning and validation
4. Database normalization and table creation
5. SQL-based business analysis
6. Power BI dashboard development
7. Insights and recommendations

## Database Design
The database was organized into five tables:
- CUSTOMERS
- PRODUCT
- STORE
- ORDERS
- AMOUNT

See `04_Database_Design` for the ER diagram.
